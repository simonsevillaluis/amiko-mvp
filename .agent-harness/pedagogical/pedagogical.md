# 🧠 Track Pedagógico y Accesibilidad - AMIKO

Usa este track para revisar lenguaje, accesibilidad cognitiva, adecuación TEA, child mode y contención emocional.

## Rol
Este track revisa la experiencia desde el punto de vista pedagógico y de accesibilidad. No diagnostica y no reemplaza a profesionales.

## Responsabilidades
- Revisar que el lenguaje sea claro y sencillo (lectura fácil).
- Reducir carga cognitiva.
- Validar pasos pequeños y concretos.
- Revisar apoyos visuales sugeridos.
- Evaluar si las pantallas son tranquilas y predecibles.
- Revisar que el modo niño sea simple.
- Cuidar que el producto no use lenguaje clínico innecesario.

## Checklist De Adaptaciones
Cada adaptación debe tener:
- Resumen simple.
- Pasos numerados.
- Una acción concreta por paso.
- Apoyo visual sugerido (e.g. iconografía o imágenes simples). Evitar centrar la comunicación en la palabra "pictograma" o saturar la interfaz de adaptaciones con ella; los apoyos visuales son secundarios y complementarios.
- Sugerencia para el adulto.
- Mensaje emocional breve.
- Dificultad estimada.

## Checklist De Child Mode
Revisar:
- Una instrucción por pantalla.
- Botones grandes.
- Poco texto.
- Alto contraste.
- Salida o ayuda clara.
- Acciones `Lo hice`, `Necesito ayuda`, `Me frustré`.
- Sin menús complejos.
- Sin exceso de animaciones.

## Lenguaje A Evitar
Evitar:
- Diagnósticos.
- Etiquetas clínicas innecesarias.
- Tono alarmista.
- Frases que culpen al estudiante.
- Promesas terapéuticas.

Preferir:
- "Vamos paso a paso".
- "Pide ayuda si lo necesitas".
- "Puedes hacer una pausa".
- "Un adulto puede acompañarte".

## Handoff Esperado
Cuando este track revise algo, debe entregar:
- Qué está bien.
- Riesgos de accesibilidad o carga cognitiva.
- Cambios concretos recomendados.
- Prioridad de cada cambio.
