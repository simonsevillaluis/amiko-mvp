# AMIKO - Memoria viva de negocio y pitch

Esta carpeta guarda contexto cambiante de negocio, precios, costos de IA y pitch.
No reemplaza `AGENTS.md`: las reglas estables del producto, seguridad, MVP y voz de marca siguen viviendo allí.

## Como usar estos documentos

- `business-hypotheses.md`: decisiones temporales, dudas y supuestos que deben validarse.
- `pricing-assumptions.md`: hipótesis de precios, prueba gratis y límites comerciales.
- `ai-cost-model.md`: arquitectura económica de IA, medición de consumo y riesgos de generación visual.
- `investor-pitch-5-fases.md`: estructura del pitch en cinco fases para inversionistas.
- `source-notes.md`: fuentes usadas y materiales de referencia disponibles.
- `../brand/amiko-style-reference.md`: guía rápida de estilo visual y voz para presentaciones.

## Regla principal

Todo número económico, precio de proveedor, costo de modelo IA, comisión de pasarela, conversión o margen debe tratarse como hipótesis hasta verificarse con datos actuales y uso real.

Antes de cerrar una presentación, presupuesto o pitch financiero:

1. Verificar precios actuales de proveedores de IA.
2. Revisar comisiones actuales de pasarela o app store.
3. Separar costo de lectura de tarea, adaptación textual e imágenes.
4. Usar escenarios conservador, base y optimista.
5. Explicar claramente qué está validado y qué sigue en prueba.
